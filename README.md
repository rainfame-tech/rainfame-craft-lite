# Rainfame Craft Lite

A free Claude skill that turns NN/g's 10 usability heuristics, Apple's Human Interface Guidelines, Material Design 3, the Laws of UX and WCAG 2.2 into rules you can mark pass or fail. Ask Claude to write a design standard for your product, then design or fix screens against it.

Built and tested on LicencePath, a live UK driving licence app made by Rainfame.

## Install in Claude Code

```
/plugin marketplace add rainfame-tech/rainfame-craft-lite
/plugin install rainfame-craft-lite@rainfame
```

In the Claude app, you can also add the `plugins/rainfame-craft-lite` folder as a plugin, or copy `skills/craft-ui-standard` into your skills.

## Try it

- "Write a design standard for my booking app"
- "Check this screen against the craft standard"
- "Set up a type scale and colour roles for my product"
